# site-finmo — сайт finmo.integram.io (конструктор финансовых моделей)

Перенос finmo.integram.io с Тильды на свой хостинг, с новым дизайном и без интеграций Тильды (issue #873). Тексты, цены, ссылки и реквизиты — как на Тильде (правились только опечатки и регистр заголовков). Устроен по образцу [`site-mvp/`](../site-mvp/README.md): свой vite-конфиг, свои компоненты, свой `dist-finmo/`; с основным сайтом код не делит (общая только типографика `src/lib/typography.mjs`).

Страницы (статический HTML, React в браузер не отправляется):

- `/` — лендинг: проблемы Excel, решение, сравнение, продукт, состав решения, предложение, обратный звонок;
- `/success` — «Спасибо за ваше обращение!» (сюда ведёт успешная форма).

## Сборка

```
npm run dev:finmo     # vite dev-сервер (порт 5177; без пререндера)
npm run build:finmo   # vite build + scripts/prerender-site-finmo.mjs → dist-finmo/
node --test tests/site-finmo.test.mjs
```

`SITE_URL` (по умолчанию `https://finmo.integram.io`) и `METRIKA_ID` (по умолчанию `104176620` — счётчик с Тильды) можно переопределить окружением. Метрика без вебвизора, цель `lead` уходит после ответа `order.php` «принято». Шрифты системные, внешних шрифтов нет.

## Форма и оплата

- «Есть вопросы? Заказать звонок» (`form=callme`: имя, телефон) → `/order.php` → `/success`. `order.php` — копия `site-mvp/public/order.php` с одной формой: проверка Referer, honeypot `website`, лимит 3 заявки с IP за 10 минут, телеграм + почтовый дубль.
- «Купить за 200 тысяч рублей» ведёт, как и на Тильде, на платёжную страницу Точки (`checkout.tochka.com/…`) — это не интеграция Тильды, оставлена.
- «Индивидуальные условия» — якорь на форму звонка.

Конфиг формы — `order-config.php` рядом с `order.php` (образец `order-config.example.php`, в git не входит): `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ORDER_EMAIL_TO`, `ORDER_EMAIL_FROM`, `TELEGRAM_API_BASE`. Без токена и почты `order.php` отвечает 500.

## Выкладка

1. `npm run build:finmo`.
2. Содержимое `dist-finmo/` (включая `.htaccess`) — в корень сайта finmo.integram.io.
3. Один раз положить `order-config.php`.
4. Перевести DNS `finmo.integram.io` с Тильды на сервер, выпустить сертификат.
5. Проверить `/`, `/success` без слеша, тестовую заявку.

## Что не перенесено

Тильдовские скрипты, форма и CDN; декоративные фоны (ноутбук на первом экране, фон-«blob») и картинка со статистикой «Быстрее в 10 раз / Дешевле в 5–10 раз» — она стала вёрсткой. Скриншоты слайдера «Состав решения» и продукта скачаны и пережаты в `public/img/*.webp`; слайдер заменён лентой карточек.

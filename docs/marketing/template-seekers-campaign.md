# Кампания «Шаблоны»: запуск пилота

План — `template-seekers-plan.md`, этот файл — порядок запуска по нему
(issue #790). Три темы: табель Т-13, приход-расход-остаток, журнал выдачи
материалов. Бюджет-кластер не берётся (решение #763).

## Что уже сделано в репо

- Страницы `site-excel/tpl/*.json` → `/tabel-ucheta-rabochego-vremeni/`,
  `/uchet-prihoda-rashoda-materialov/`, `/zhurnal-vydachi-materialov/`:
  сверху две кнопки («Скачать Excel» и «Открыть онлайн»), формы на первом
  экране нет; ниже — что внутри шаблона, боль и онлайн-версия, своя форма
  «своя копия» (`order.php`, `kind=copy`, `tpl=<slug>`), FAQ, мостик на главную.
- Шаблоны .xlsx — `scripts/make-tpl-workbooks.mjs` (exceljs), файлы в
  `site-excel/public/files/`. При правке шаблона: запустить скрипт, закоммитить файл.
- `order.php`: вид заявки `copy` с полями `tpl` и `who`; материалов и описания
  не требует; double opt-in не применяется (он только у `demo`).
- Цели воронки на странице: `tpl_view` (загрузка), `tpl_download` (скачал),
  `tpl_demo_open` (открыл онлайн), `lead` (отправил форму копии), плюс
  `landing_cta` на мостике.
- JSON кампании: `template-seekers.keywords.json` (3 группы по 9–12 фраз,
  у каждой своя посадочная и `utm_campaign=tpl-<slug>`),
  `template-seekers.ads.json` (по 3 объявления),
  `template-seekers.negatives.json` (список из плана §5; общий
  excel-cpa-negatives.json не применяется). Профиль `CAMPAIGN_PROFILE=tpl`:
  максимум кликов, только поиск, будни 8:00–20:00, потолок 15 ₽,
  1 000 ₽/нед на группу.

## Порядок запуска

1. **Демо-базы на ideav.ru** — по `docs/excel-to-app-demo-playbook.md`, три
   базы: `ideav.ru/tabel-t13/`, `ideav.ru/sklad-prirash/`,
   `ideav.ru/zhurnal-vydachi/` (адреса уже зашиты в страницы — при другом
   имени базы поправить `demo` в `site-excel/tpl/*.json`). Импорт —
   соответствующий .xlsx из `site-excel/public/files/`, пользователь `guest`
   с ролью только-чтение (движок сам пускает гостя без формы входа).
2. **Цели Метрики** — созданы 27.10.2026 через Management API
   (счётчик 112716451): `tpl_view` = 675106596, `tpl_download` = 675106600,
   `tpl_demo_open` = 675106603; `lead` = 627071307 (существующая).
   Идентификатор события — в условии цели, поле `url` типа `exact`.
   Грабля: Windows-curl портит UTF-8 в теле запроса — JSON гонять файлом
   через node, а не аргументом curl.
3. **Сборка и выкладка**: `SITE_URL=https://excel-to-app.ru
   METRIKA_ID=112716451 npm run build:excel` → содержимое `dist-excel/` в
   корень сайта. `order.php` перед заливкой сверить с прод-версией: на проде
   он бывал впереди git (#657).
4. **Директ, сухой прогон**:
   `CAMPAIGN_PROFILE=tpl SITE_URL=https://excel-to-app.ru
   METRIKA_ID=112716451 node scripts/direct-create-cpa-campaign.mjs`
5. **Директ, создание**: то же с `--apply`. Токен — `~/.claude/excel-to-app-token.json`
   (проверено 27.10.2026: токен кабинета excel-to-app работает с API;
   заметка об ошибке 58 у собственного приложения в excel-cpa-campaign.md
   устарела). Кампании создаются остановленными, объявления — черновиками:
   отправить на модерацию и включить кампании только после выкладки
   страниц (шаг 3), иначе модерация словит 404.
6. **Отчёт по пилоту** — через 2 недели, пороги из плана §6:
   скачивание ≥ 20 % визитов (стоп < 8 %), открытие онлайн ≥ 8 % (< 3 %),
   копий ≥ 10 (< 3), ведут учёт на 3-й день ≥ 30 % копий, разговор о платной
   работе ≥ 1. Отчёт: запросы, ступени воронки по целям, активность копий.

## Решения раздела 7 плана, принятые по умолчанию

- 7.1 — шаблон отдаётся без контакта (да);
- 7.2 — первые две недели копии делаются руками, на страницах обещание
  «в течение часа в рабочее время»;
- 7.5 — первыми сделаны табель и склад; журнал выдачи — третья страница,
  потому что она названа в задаче #790 и дала один из трёх лидов отчёта.
- 7.3 (кто звонит активным на 3–5 день) — не решён: без него пилот проверит
  только верх воронки.

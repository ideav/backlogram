# Шаблон письма клиенту «Приложение готово»

Письмо, которое отправляется автору заявки с сервиса «Из Excel — приложение»
(лендинг excel-to-app.ru / ideav.ru/excel-to-app.html), когда демо-приложение
собрано. Тон — дружелюбно-деловой, без технического жаргона; в конце — мягкий
переход к платному разбору (оффер 20 000 ₽).

## Как отправлять

- **Тема:** `Ваше приложение для {{тематика_кратко}} готово — Интеграм`
- **From:** `Интеграм <welcome@ideav.ru>` · **Reply-To:** `abc@integram.io`
- Клиента — в `To`, себя — в `Bcc` (для контроля отправки).
- Кодировка тела — UTF-8, `Content-Transfer-Encoding: 8bit`; тему MIME-кодировать
  (`=?UTF-8?B?…?=`), иначе кириллица в теме бьётся.
- Отправка с сервера: `mail()`/exim с `-f welcome@ideav.ru` (домен с SPF/DKIM,
  иначе mail.ru/Яндекс кладут в спам).

## Плейсхолдеры

| Плейсхолдер | Что подставить | Пример |
|---|---|---|
| `{{тематика}}` | тематика из заявки | приложение для поиска и создания заказов в интернет-магазине |
| `{{тематика_кратко}}` | 1–3 слова для темы письма | интернет-магазина |
| `{{app_url}}` | адрес базы | https://ideav.ru/nteaclub/ |
| `{{login}}` / `{{password}}` | доступ бизнес-роли | seller / ChaySeller2026 |
| `{{что_внутри}}` | 2–4 пункта по данным клиента | см. образец ниже |
| `{{цена_разбора}}` | цена разбора | 20 000 ₽ |
| `{{вилка_разработки}}` | ориентир стоимости | 50–100 тыс. ₽ |

## Тело письма

```text
Здравствуйте!

Вы оставляли заявку на сервисе «Из Excel — приложение» (тематика: {{тематика}}).
Приложение готово — мы собрали его из вашего файла, и его уже можно посмотреть
и потрогать.

Ссылка на приложение:
{{app_url}}

Доступ:
    логин: {{login}}
    пароль: {{password}}

Что внутри:
{{что_внутри}}

Это бесплатная демонстрация — заготовка на ваших данных, чтобы убедиться, что
идея рабочая. Дальше, если захотите довести её до полноценного рабочего решения,
следующий шаг — разбор процесса за {{цена_разбора}}: по нему мы с помощью ИИ
пишем техническое задание и называем стоимость разработки (обычно
{{вилка_разработки}}, включая эти деньги за разбор).

Если что-то поправить в демо или обсудить разбор — ответьте на это письмо или
напишите нам в Telegram: @qdmadept, либо на почту abc@integram.io.

С уважением,
команда Интеграм
https://ideav.ru
```

## Образец блока «Что внутри» (чайный магазин, заявка #25)

```text
— Каталог: 198 товаров из вашего прайса, разложенные по 15 категориям, у каждого — цена за грамм.
— Создание заказов: продавец находит позиции по названию или категории, заводит заказ на покупателя и добавляет товары с граммовкой — суммы считаются автоматически. У заказа есть статусы (новый, в сборке, отгружен).
— Для примера уже заведено три заказа, чтобы сразу было видно, как это выглядит в работе.
```

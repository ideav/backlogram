# Цели Метрики для «Обсудить разбор» (issue #591)

Двухэтапный CTA на `/excel-to-app.html#razbor` (PR #592) шлёт три JS-события —
по одному на каждый канал второго этапа. Код уже отправляет; остался разовый
шаг в интерфейсе Метрики (счётчик **108758829**).

## Какие события шлёт код

```js
ym(108758829, 'reachGoal', 'razbor_tg')        // клик «Написать в Telegram» (@qdmadept)
ym(108758829, 'reachGoal', 'razbor_call')      // клик «Позвонить» (tel:+79955060167)
ym(108758829, 'reachGoal', 'razbor_callback')  // успешная отправка формы «Заказать звонок»
```

С каждым событием передаётся параметр `page: 'excel-to-app'`.

## Как завести (3 раза по одной минуте)

**metrika.yandex.ru** → счётчик **108758829** → **Настройка → Цели → Добавить цель**:

| Название (для себя)             | Тип условия          | Идентификатор цели |
|---------------------------------|----------------------|--------------------|
| Разбор — Telegram               | JavaScript-событие   | `razbor_tg`        |
| Разбор — звонок по телефону     | JavaScript-событие   | `razbor_call`      |
| Разбор — заказ обратного звонка | JavaScript-событие   | `razbor_callback`  |

Идентификаторы — буква-в-букву, маленькими, с подчёркиванием: они должны
совпадать со строками в `src/pages/ExcelToApp.tsx`.

`razbor_callback` — это готовая заявка с телефоном (самое ценное из трёх):
её стоит добавить в Директе как конверсионную цель рядом с `lead`
(см. [metrika-lead-goal-setup.md](metrika-lead-goal-setup.md)).

## Проверка после деплоя

1. Открыть `/excel-to-app.html#razbor` → «Обсудить разбор» → кликнуть каждый канал.
2. Метрика → **Отчёты → Конверсии** — в течение нескольких минут появятся
   конверсии по трём целям (или смотреть «В реальном времени»).

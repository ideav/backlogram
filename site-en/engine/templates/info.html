Welcome to Integram

This is your Integram instance, a universal platform for working with data. Here you can create tables and queries, build forms, import data from files and grant access to other users.

Where am I?

This is the home page of your Integram instance. Use it as a sandbox for experiments or build a large app for hundreds of users.

On the left is the organizer menu, which you can customize with links to any workspace. Use the icon at the bottom left to configure it.

The small menu at the top right links to My account, where you can create another sandbox, get your referral link to earn from the payments of customers you bring, and change your plan.

You can customize literally everything here, including this page, which you can edit in the Files menu — here it is.
You have full power here, so be careful at first!

Enable / disable / reset hints

Each workspace shows a short intro in 2–3 pop-up hints. After they are shown once, they won't appear again unless you reset hints here.

See which tables exist in the system

The Tables menu. Even an empty system already has the basic tables every app needs: users, roles, queries and related lookups.

You can add columns and records to these tables, but we don't recommend deleting anything that is already there.

Go to tables
Import data from a file into a table

The Upload menu. Import files into an existing table or create a new table straight from a file with the wizard.

Grant access to users of this database

The Users menu. All users of the system are stored here.

Initially only the database owner is here, but you can add other users and assign them roles.

Go to users
View the data structure

The Structure menu. Quickly understand an unfamiliar database: see all tables and their links on one screen without opening each table.

Go to structure

💡Finding a table

Type a name in the search bar at the top to quickly find a table in the list. You can move tables into any folder and create new folders here.

💡Creating a table

Click "Create table" (or "+") and enter a name. Add fields and pick a data type for each. Put the table in a folder and its position is remembered in this browser.

💡Opening a table

Click a table name in the list to view and edit its data.

# site-mvp — сайт mvp.care (студия «Интеграм»)

Перенос mvp.care с Тильды на свой хостинг, с новым дизайном и без интеграций Тильды (issue #872). Тексты, цены, кейсы, ссылки и реквизиты — как на Тильде (правились только опечатки). Устроен по образцу [`site-excel/`](../site-excel/README.md): свой vite-конфиг, свои компоненты, свой `dist-mvp/`; с основным сайтом и site-excel код не делится.

Страницы (статический HTML, React в браузер не отправляется):

- `/` — главная;
- `/success` — «Спасибо за ваше обращение!» (сюда ведёт каждая успешная форма);
- `/ideav_callme` — форма «Закажите звонок».

`/index1` (старая страница «I d e a V») не переносится: `.htaccess` отдаёт 301 на `/`.

## Сборка

```
npm run dev:mvp     # vite dev-сервер (порт 5176; страницы без пререндера)
npm run build:mvp   # vite build + scripts/prerender-site-mvp.mjs → dist-mvp/
```

`SITE_URL` (по умолчанию `https://mvp.care`) и `METRIKA_ID` (по умолчанию `94166541`) можно переопределить окружением. Метрика: стандартный тег без вебвизора, цель `lead` уходит после ответа `order.php` «принято». Шрифты системные, внешних шрифтов нет.

## Формы

Все формы шлют JSON в `/order.php` (с JS; без JS — обычный POST) и после успеха переходят на `/success`:

| `form` | где |
| --- | --- |
| `phone-hero` | «Ваш телефон» → «Связаться» (имя необязательно) |
| `book-hours` | «Забронируйте время аналитика»: email или телефон + часы 5/10/20 |
| `phone-save` | «Экономить время и нервы» |
| `question` | «Сомневаетесь или есть вопросы?» (телефон + задача) |
| `callme` | `/ideav_callme`: имя, телефон, email |

**Временное решение.** На Тильде форма `book-hours` вела на оплату часов. Оплаты на новом сайте нет: это заявка («Забронировать»), оплату и время согласует менеджер при ответе. Кнопка и подпись поправлены минимально.

`order.php` (по образцу `site-excel/public/order.php`): проверка Referer (свой хост), honeypot `website`, лимит 3 заявки с IP за 10 минут, доставка телеграм первым и почтовый дубль. В сообщении — форма, поля, страница, UTM.

## Конфиг формы

В git секретов нет. Конфиг — из окружения или из `order-config.php` рядом с `order.php` (образец — `order-config.example.php`, файл в `.gitignore`): `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ORDER_EMAIL_TO`, `ORDER_EMAIL_FROM` (по умолчанию `welcome@ideav.ru`), `TELEGRAM_API_BASE` (прокси к Bot API, если нужен). Без токена и без почты `order.php` отвечает 500 — заявку не теряем молча.

## Выкладка

1. `npm run build:mvp`.
2. Содержимое `dist-mvp/` (включая `.htaccess`) — в корень сайта mvp.care.
3. Один раз положить на сервер руками `order-config.php` (из `order-config.example.php`) рядом с `order.php`.
4. Проверить: `/success` и `/ideav_callme` открываются без слеша, `/index1` даёт 301 на `/`, тестовая заявка доходит.

## Что не перенесено

Тильдовские скрипты, формы и оплата, картинки-декор с `tildacdn.com` (оставлены только три скриншота «способов работы», скачаны в `public/img/`), страница `/index1`. Ссылка под текстом согласия на ПДн в исходнике не была ссылкой, текст оставлен как есть.

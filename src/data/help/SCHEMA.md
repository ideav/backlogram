# Формат раздела помощи /help.html (backlogram#946, эпик ideav/crm#5603)

Каждый раздел — файл `src/data/help/<id>.mjs`, ES-модуль без импортов:

```js
// <Раздел> — статьи помощи /help.html (backlogram#NNN).
// Источники: <пути и ссылки, откуда взяты факты>.
export const SECTION = {
  id: 'structure',                 // = имя файла
  title: 'Структура данных',       // заголовок раздела
  lead: 'Одна-две фразы: что умеет раздел и зачем он клиенту.',
  articles: [
    {
      id: 'structure-dropdown',    // латиница-кебаб, префикс = id раздела, уникален по сайту (якорь #id)
      title: 'Выпадающий список из справочника',   // задача клиента, как он её назвал бы
      ask: [                        // 3–6 формулировок вопроса живым языком — по ним ищет консультант
        'как сделать выпадающий список',
        'выбор значения из справочника',
        'поле со списком',
      ],
      tags: ['справочник', 'ссылка', 'реквизит', 'select'], // синонимы и термины для поиска
      level: 'start',               // 'start' — пользователь в интерфейсе, 'pro' — разработчик (API, SQL, шаблоны)
      summary: 'Короткий ответ в 1–2 предложения — консультант показывает его первым.',
      steps: [                      // 2–8 шагов «что нажать / что вызвать», каждый — одно действие
        'Откройте «Структура» и создайте таблицу-справочник «Статус» с колонкой-названием.',
        'В нужной таблице добавьте реквизит со ссылкой на «Статус».',
      ],
      blocks: [                     // необязательно: пример, код, таблица, оговорка, скриншот
        { t: 'p', text: 'Текст; `код` в обратных кавычках.' },
        { t: 'list', items: ['…', '…'] },
        { t: 'code', lang: 'bash', code: 'curl -s -H "X-Authorization: $TOKEN" "https://ideav.ru/mydb/object/42?JSON"' },
        { t: 'note', text: 'Оговорка или подводный камень.' },
        { t: 'table', head: ['Параметр', 'Смысл'], rows: [['FR_', 'фильтр «от»']] },
        { t: 'img', src: '/help-img/<id статьи>-<номер>.svg', alt: 'Что на схеме — по нему ищут и его читают скринридеры', caption: 'Подпись под схемой (необязательно)' },
        { api: true, t: 'code', lang: 'bash', code: '…' }, // api: true — тот же шаг через API (см. ниже)
      ],
      links: [                      // необязательно: куда читать дальше
        { href: '/queries.html#address', text: 'Запросы: адрес вызова' },
      ],
    },
  ],
}
```

Правила текста:

- Русский язык, на «вы», коротко и по делу. Без маркетинга и без выдуманных возможностей:
  каждый факт — из источника (код ядра, docs, справочники сайта, help.integram.io).
  Не уверен — не пиши.
- Клиенты обезличены: никаких названий компаний-заказчиков, имён, живых адресов их баз,
  реальных данных. Примеры — на базе `mydb`, хост `https://ideav.ru`, нейтральные таблицы
  («Клиенты», «Заказы», «Задачи», «Склад»). Демо-бренд «Atex» допустим.
- Токены и пароли в тексте — только `$TOKEN`.
- Картинки (crm#5614, crm#5626): у популярных действий «в интерфейсе» — 1–3 схемы на статью, сразу
  после `steps`. Это не скриншоты, а схемы НОВОГО интерфейса таблицы в одном стиле: их рисует
  `node scripts/generate-help-schemes.mjs` (описания — `scripts/help-schemes/*.mjs`) в
  `public/help-img/<id статьи>-<номер>.svg`. Подписи кнопок и окон на схеме — дословно из кода
  ideav/crm (`js/integram-table/`, `templates/tables.html`); оранжевые номера = номера шагов
  статьи. Старый интерфейс показывать только там, где действия в новом нет, с пометкой
  «Старый интерфейс таблицы». `alt` обязателен; проверяют tests/issue-5614-help-screenshots.test.mjs
  и tests/issue-5626-help-review.test.mjs.
- Статья `level: 'start'` описывает шаги в интерфейсе. Вызовы API (curl, `_d_*`, `_m_*`) и
  заметки про поля ответов в ней помечаются `api: true`: страница выводит их отдельной рамкой
  «То же через API — для ИИ-агента или разработчика», бейдж статьи — «в интерфейсе · есть API».
- Неразрывные пробелы руками не ставить (их расставляет сборка).
- Ссылки — только на страницы ideav.ru (`/api.html#…`, `/queries.html#…`, `/templater.html#…`,
  `/triggers.html#…`, `/stored-procedures.html#…`, `/knowledge-base/<slug>` и т.п.), якоря сверять
  с `id` в `src/data/*Docs.mjs`; внешние — только документация MySQL/PHP.
- В строках JS: одинарные кавычки или обратные кавычки шаблона для `code`; внутри `text`
  обратная кавычка значит «код», поэтому шаблонные строки для `text` не использовать.
